# data viewer v0 (簡易プロットアプリ)

PySide6 + pyqtgraph + NumPy で作ったWindows向けデスクトップアプリの初期バージョンです。

## 1. セットアップ（Windows / PowerShell）

Python 3.11〜3.13 の64bit版をインストールしてください。
このフォルダでPowerShell/CMDを開いて、以下を順番に実行します。

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```
(仮想環境の構築と必要なパッケージのインストール、アプリの起動)
2回目以降は最後の行だけで起動できます。

PowerShellを開くには、このフォルダのエクスプローラーのアドレス欄に `powershell` と入力してEnterを押せばOKです。

## 2. 最初の使い方

1. 起動すると `sample_data` フォルダのファイルが表示されます。
2. Graph 1 へ `demo.dat` をドラッグ＆ドロップします。
3. ダイアログで `x = Field(T)`, `y = Rxx(ohm)` を選択して「OK」。
4. 「計算式を使用」をチェックすると、例として `X = x`, `Y = y*2` などを入力できます。
5. 測定フォルダに切り替える場合は左側の「フォルダを開く」を押します。
6. `demo_comma.csv` はヘッダー3行・カンマ区切りの区切りタイプが違うデータのサンプルです。ファイルをダブルクリックしてクイックルックから区切り文字やヘッダーの行数を変更できます。

## 3. マウス操作

| 操作 | 動作 |
|---|---|
| ホイール回転 | 拡大・縮小 |
| 中ボタンドラッグ | Pan |
| 左ドラッグ（範囲モード） | 指定した矩形を拡大 |
| 左ドラッグ（Panモード） | Pan |
| Auto | 全データが含まれる範囲に調整 |
| Undo / Ctrl+Z | 直前の表示範囲に戻す |
| 軸クリック・「軸設定」 | 軸範囲・対数・ラベルの設定 |
| 曲線をダブルクリック | 曲線のプロパティ設定 |
| 「2点測定」モードで2回クリック | マーカーA/BとΔx・Δy・傾き |
| マーカーをドラッグ | データ点に吸着して移動 |
| 座標チェック | カーソル近くのデータ点と行番号を表示 |

5個以上のグラフを作っても内容は保持されます。表示するグラフは左のリストで切り替えてください（同時に最大4個）。

## 4. ファイルの読み込み・更新

標準は「空白またはタブ区切り・ヘッダー1行・UTF-8」です。
ファイルをダブルクリックするとクイックルックが開き、区切り・ヘッダー数・列名に使う行・文字コードを変更できます。
データ本体は利用時だけ読み込み、以後はメモリ上のキャッシュを利用します。
「更新」を押すと左側で選択したファイルだけ再読み込みし、そのファイルを使う曲線を更新します。
読み込みエラー時、以前のキャッシュは保持します。

**注意:** 
数値列だけのテキストデータが対象。文字列を含むデータ列・日時列・途中にあるコメント行等の高度な形式は未対応です。
1ファイルが極めて巨大なときのメモリ上限についてはテストしていません。

## 5. 保存・出力

各グラフ右上の「⋯」から以下が使えます。
- JSON: データの参照先、列の対応、数式、色、軸設定を保存。元データ本体は含めません。
- PNG / SVG: 現在のグラフを画像出力。
- テンプレート: 軸設定とカラーパレットを名前をつけて保存・適用。

JSON保存グラフは、上部の「ファイル」→「保存したグラフを開く」から開けます。
テンプレートはユーザーのアプリ設定領域の `templates.json` に保存します。

## 6. コードの役割

```text
main.py                  起動用。原則として変更不要
viewer/
  main_window.py         メイン画面と各モジュールの呼び出し
  file_tree.py           ファイル・フォルダの階層表示
  reader.py              テキストファイルから数値を読み込む
  data_manager.py        キャッシュ、ファイル単位の更新、別スレッド読み込み
  formula.py             数式の安全な解釈・配列演算
  models.py              共有データ構造（CurveSpec、ReaderOptions等）
  graph_panel.py         グラフ1枚分の操作・描画・2点マーカー
  dialogs.py             計算式、クイックルック、軸設定の画面
  serialization.py       グラフJSONとテンプレートの保存
sample_data/             動作確認用データ
  demo.dat
  demo_comma.csv
tests/
  test_core.py           GUIに依存しないテスト
requirements.txt         必要なライブラリ
```

## 7. 制限事項

- 未表示グラフの再描画抑制と、大量ファイルのメモリ上限管理は未実装。
- 巨大データ上の座標探索は高速化のため粗探索→近傍探索であり、非単調で非常に巨大なデータでは厳密な最近傍とは限りません。
- Undoは軸範囲の履歴のみ（曲線の削除や数式変更はUndoしません）。
- 画像のクリップボードコピー、セッション全体の保存、Redoは未実装。
- マーカーは曲線の更新や編集時にいったん解除されます。
- 対数表示の範囲入力は正数のみです。
- Qt/pyqtgraphのバージョン・OSによるイベント処理差はGUI実機確認が必要です。

## 8. 数値計算のテスト

GUIなしでテストを実行する場合、pytestがインストールされていれば：

```powershell
.venv\Scripts\python.exe -m pip install pytest
.venv\Scripts\python.exe -m pytest -q
```
